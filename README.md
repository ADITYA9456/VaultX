

# 🚀 VaultX <Your Own Password Manager /> 🔐

Welcome to **VaultX** — a sleek, secure, and easy-to-use password manager built with **ReactJS**, **Tailwind CSS**, and **MongoDB** (or **localStorage** fallback). Manage all your website credentials in one place and keep your online life organized!

---

## ✨ Features

✅ **Add & Save Passwords**
✅ **Store Website URLs, Usernames, Passwords**
✅ **Show / Hide Passwords with Masking**
✅ **Edit & Delete Stored Entries**
✅ **Copy Credentials with One Click**
✅ **Responsive & Clean UI (Tailwind-powered)**
✅ **Data Persistence with MongoDB or LocalStorage**
✅ **Modern, GitHub-linked Interface**

---

## 🏗️ Tech Stack

* ⚛️ **ReactJS** — frontend framework
* 🎨 **Tailwind CSS** — for modern, responsive styling
* 🌐 **MongoDB / LocalStorage** — for data storage
* 📦 **React Icons** — for beautiful icons
* 🛡️ **Security** — passwords masked & copy-enabled

## 🚀 Getting Started

### 1️⃣ Clone the Repo

```bash
git clone https://github.com/your-username/vaultx.git
```

### 2️⃣ Navigate to Project Folder

```bash
cd vaultx
```

### 3️⃣ Install Dependencies

```bash
npm install
```

### 4️⃣ Run the App

```bash
npm start
```
